My Monday, reviewed in one line: the alarm showed up, my motivation ghosted me, and my coffee billed me for overtime. It lands because it is the whole Monday experience in three beats — the one thing that worked (the alarm), the one thing that didn't (me), and the one thing keeping me upright (coffee, now charging extra for the trouble).

## Run it

```sh
python3 main.py
```

This writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) — exactly one line, under 200 characters, no trailing newline.
